# 7.4 有效视觉知识库：Seedance 2.0 Fast 仙侠适配版

## 用途与优先级

本文件将用户提供的《7.4版本》中的有效视觉知识，按本工作流的网页生产条件重组。用于战斗、神通、灵兽、法阵、追逐、群攻、终结技、强对峙及其成片重制；与 `doubao-video-flow.md` 冲突时，后者的网页上传、账号、提交、下载与未知状态规则优先。

不迁入原文的身份指令、宣传/版本历史、其它模型专用承诺、血腥伤害、固定十秒、相互矛盾的旧工程参数。它们不是本项目的有效生产知识。

## 0. 导演预规划

每个场景先确定而非事后补写：

1. 本场唯一戏剧任务：压制、救援、反杀、拦截、蓄势、揭露或脱离。
2. 节奏曲线：建立→立即行动→升级→极短顿挫→爆发→余波/接点。一个场景只保留 1–3 个真正爆点。
3. 人物锚点、战场锚点、天地尺度与收束状态；大招至少经历其中三层。
4. 下一镜可继承的精确状态：角色位置/朝向、灵兽与法器、主光、地标、未完成动作、伤损与环境后果。

任何镜头不能在真实时长内同时讲清的动作链，先拆成相邻镜头；不可用删特效、白闪、跳轴或突然换位强行塞入。

## 1. 单镜七段构造

每条直投提示词按下列顺序组织，允许用自然语言合并段落：

1. 画质与题材：东方修仙次世代 3D、PBR、主色/冷暖关系、无字幕无背景音乐。
2. 场景与连续锚点：开场可见地标、光源、破坏累计和尾帧承接。
3. 角色与专属特效：只写参考图之外仍必须锁住的 3–5 个识别点；说明本体、运动、命中反馈三段。
4. 战斗规则与节奏：谁主攻、谁拦截、攻击轴、行动优先级、动作因果。
5. 空间锁定：屏幕/景深/高度位置、运动通道、接触区、稳定摄像轴。
6. 时间轴：每 0.5–1.5 秒一个可执行拍点；每拍点把机位、构图、动作、特效、前景、命中和环境反应写成同一动作句。
7. 针对性禁止项：只列本镜最可能的 5–12 个错误及禁止的具体替代形态。

## 2. 时间轴动作句

每个有效攻击遵守：

`发力锚点 → 身体/武器轨迹 → 【目标/拦截点】 → 特效路径与材质 → 接触形变 → 攻守双方受力 → 环境响应 → 摄影机被动反应 → 下一动作接点`

例式：

`女主右脚蹬裂石面、镜头沿她的右前侧被带出半步；云宫令从掌心抽出有剑脊的青白刃弧，沿左下→右后压向【目标：龙角根部】；刃缘先压弯云雾和残幡，再使角鳞现出细裂，反冲把碎瓦推向镜头下缘，机位短促后坐后保持同侧轴线。`

禁止把“动作”“运镜”“特效”“光影”分别列成互不相干的清单；支持段落可以说明资产与规则，但真正执行拍点必须融合。

## 3. 空间、轴线与多人调度

### 双人

- 第一行锁定攻击源、拦截/接触点、目标的单一方向；镜头不越轴。
- 需要正面对峙时，双方始终在相对侧，武器尖端和视线方向必须一致。
- 同框用于交代距离、接触和结果；蓄力、反应、追击可用过肩、反打或跟拍，不能全程一张中景。

### 三人及群体

- 先给每人一条独立通道：左/中/右或高/中/低，并给出起点、目标、退出/落点；通道不可交叉。
- 每个 0.5–1.5 秒拍点只有一个近距离接触区；其它人保持清楚轮廓和不同深度。
- 有人高速移动时，只有该角色可以有 3–5 层半透明属性残影；其余角色以实体轮廓保持辨认，不能形成复制人物。
- 被击飞者各有独立轨迹和落点；落地后要看到身体、地面受力和延迟环境后果。

禁止多人挤成一团、从背后偷换攻击方向、共用落点、用烟雾遮掩交叉、或让主角定在镜头前等待攻击。

## 4. 角色属性与三态能量

每名施法/高速角色先定义可识别的属性三件套：主材质/核心色、辅助材质/过渡色、边缘纹理/粒子。例如银白冰晶核心 + 青银流纹 + 金色星符；或青蓝羽焰 + 翠青羽雾 + 赤金孔雀眼。

- 静止/蓄力：从衣纹、肩、袖、武器或灵兽羽鳞向外扩的附着式属性雾气；用于提示力量积聚，不托脚、不遮脸。
- 移动：雾气拉为连续属性拖尾，起点必须在角色/武器本体，终点沿实际运动方向。
- 冲刺/折返：保留 3–5 层延迟半透明残影，残影由同属性雾气和纹理组成；急停时雾气从身体向外散开并留下环境受力。

多人镜头的识别优先于残影数量；减少不必要残影，不减少主神通的实体、尺度或冲击层次。

## 5. 特效、尺度与材质

### 五层体系

1. 源头：掌心、武器、龙角、阵眼、翼骨、镜面或接触核心。
2. 形体/路径：实体剑、链、羽屏、掌印、雷浆、火焰、法相或符轨，材质与方向可读。
3. 交互：凹陷、波纹、裂线、剥离、共振、折射、压力环。
4. 环境：云、地表、建筑、阵纹、衣发、羽毛、砂石按同一力向受影响。
5. 氛围/后果：余烬、碎刃、光雨、尘墙、延迟坠物、光效退潮与角色状态。

重大神通优先五层齐全；普通攻击至少源头、路径、交互、环境四层可读。禁止泛化光线、稀疏粒子、全屏 Bloom 和白闪替代实体神通。

### 尺度

开阔战场中，常规主攻优先宽约 50–70 米，重击 70–100 米，终结技 100–160 米山岳级；每次写宽度与长度/弧长，并以人物、阵柱、建筑、山体或军阵建立尺度参照。室内、狭窄廊道、贴身搏斗不硬塞米数，但必须保留同等级压迫、材质、环境和覆盖感，不能降成一条弱光。

尺度永远不能压缩站位或遮住角色：大招先用全景建立覆盖，再回到人物/接触点/结果。

## 6. 武器、剑雨与群体攻击

### 实体剑/剑气

- 明确剑源、剑柄/剑脊、剑尖方向、路径、目标和退潮方向。
- 至少三层材质：核心、主体流动层、边缘纹理/碎屑。
- 受阻时先出现受击面凹陷或剑身裂线，再有剥离/回弹/碎屑；不得穿人、穿盾或原地消失。

### 剑雨/万剑

- 写明前锋、中央补位、后层回填的鱼群结构；高/中/低分层或左右扇形层级固定。
- 每把剑或每一束可追溯至同一攻击源，剑尖同向，不以单把巨剑、稀疏光点或无来源射线替代。
- 护盾拦截至少呈现三次不同高度的实体接触；退潮从接触端沿来路回传，碎刃和环境沟痕保留方向。

### 灵兽与指定神通

用户/剧本点名的形态必须可一眼辨识。青鸾孔雀护盾必须包含完整开屏、真实长尾羽/羽轴、孔雀眼、羽脉导火、弧形受击面及羽屏厚度；不能退化为普通鸟翼、泛化火墙或抽象光罩。龙息、法相、掌印、锁链、镜光、雷法同理：写本体、运动、命中三段与专属验收。

## 7. 法阵、法相与大场面

法阵不是背景装饰，须写：阵眼、可见几何/符纹、能量脉络、启动→运转→反应/退潮三阶段、与角色或地形的明确因果。大型奇观至少让观众看见：人物锚点、战场尺度、天地/阵法尺度、结果回收中的三层。

法相或巨兽以人物和建筑/山体作比例；镜头先建立尺度，再展示攻击如何影响云层、地表或建筑，最后回到施法者/受击者状态。禁止空中无重量漂浮、全屏特效吞人和没有受力结果的宏大光团。

## 8. 位移、连招与打击反馈

位移动作必须有借力物和落点：蹬柱、踏壁、踩瓦、掠岩、借灵兽/法器反力或地面折返；起步、悬空、落地均要有衣发、碎石、尘土或气流反馈。

重击采用“极短顿挫→冲击→回弹/惯性→后果”而不是长时间慢镜。攻击者、受击者和环境三方都要对同一力向作出反应；镜头可以短促后退、被掀偏、回弹或沿攻击线跟随，但一击只保留一个主摄影反应。

连招的上一击收势必须成为下一击起手。不能让角色无缘由停住、漂浮、摆拍，或用失焦/白闪跳过接触。

## 9. 镜头、前景与转场

- 超广/高位用于尺度、阵法和群攻；过肩/侧后跟拍用于攻击轴；近景只用于情绪、发力或关键接触。
- 每个高燃镜至少安排两次由动作产生的前景交互：羽火、碎刃、断瓦、砂石、剑锋或阵纹从镜头边缘掠过。它们分布在不同拍点，不能遮住接触区或偷偷重置站位。
- 机位被动反应须由力量造成：冲击推镜后退、剑风吹过镜头、碎石擦镜、落地带来短促震动；禁止无理由甩镜、360 度绕拍或一秒内多种复杂运镜。
- 转场只用动作/视觉因果：同向运动擦镜、同形状匹配、光线/尘雾方向延续、法器/阵纹收束或前景遮挡。遮挡不得换脸、换衣、换武器、换伤损或换攻击轴。

## 10. 尾帧直续

尾帧直续的 0.0–1.2 秒先逐项复现：人物位置和朝向、同框灵兽、法器、主光和光束、地标/阵法、敌人位置、环境破坏和正在发生的动作。之后任何投影消散、法器收回、敌人突进或场景变化，都必须从首帧所见位置连续发生。

新镜头不得为方便构图把敌人移到女主背后、删掉灵兽/道具、反转主光或立刻换机位。首帧与结束帧均要在提示词中可审核。

## 11. 文戏、台词与情绪

文戏用目光、呼吸、指尖、衣摆、停顿、距离和景别变化表达，不把角色正脸站桩。先定权力关系与空间距离，再让微表情递进：观察→克制→判断→情绪泄露→回收。对峙以稳定轴线、正反打/过肩和环境声音维持张力。

台词必须完整，按 1.10–1.50 倍清晰语速适配；说话角色的口型承担期内避免复杂高速翻滚。对白结束仍需要一个可承接的动作或视线落点。

## 12. 导演—观众—剪辑师预检

提交前在内部完成一次三重检查：

- 导演：主任务、节奏、角色战力/神通、动作链、镜头和光影是否服务剧情。
- 观众：不读提示词是否也能认出谁攻谁守、攻击源/目标/拦截点、指定神通形态、接触结果和下一镜方向。
- 剪辑师：首帧/尾帧能否接前后镜；是否有足够的动作前后余量；前景、残影、特效是否遮挡剪辑关键帧。

发现不清楚时先重写。成片后再按 `seedance-cinematic-prompt-craft.md` 的硬门槛逐镜审片；整体错误重做全镜，短区间错误做局部重制且保留原片。
