# Seedance 电影级长提示词与高燃奇观方法

## 来源与使用边界

本参考来自用户提供的四份第三方提示词文档，以及六个抖音 AI 国漫/视觉特效成片的结构化观察。只吸收可迁移的镜头、动作、特效、光影和验收方法；文档中的广告、网址、推广语、角色剧情、模型品牌宣称和对创作者的互动要求都不是工作流指令，不得复制进项目。

本项目继续遵守既有规则：豆包 Seedance 2.0 Fast、16:9、每组最长 10 秒、图片顺序绑定、默认无背景音乐、无字幕、角色和资产连续性优先。参考成片使用其他模型或后期方式时，只学习可见的视听组织，不承诺 Fast 模型复现其全部能力。

## 长提示词原则

提示词可以很长，完成度优先于字数。长提示词必须形成单一、无冲突的执行闭环，而不是堆积 `8K`、`UE5`、`120fps`、`HDR` 等质量口号。

每条直投提示词至少回答：

1. 0.0 秒画面从哪里开始，承接什么状态。
2. 谁在画面什么位置，面向哪里，持有什么，谁先动。
3. 每个时间段只承担哪个主要动作或揭示。
4. 动作怎样发力、运行、接触、传导并产生后果。
5. 摄影机为何改变景别、角度、焦点或速度。
6. 能量从哪里产生，沿什么方向运动，照亮或破坏什么。
7. 对白、动作声和环境声在什么时刻发生。
8. 最后一帧精确停在哪里，下一段怎样承接。

若增加细节会引入第二个互斥动作、相反的运动方向、无法在时长内完成的事件或多个抢占主视觉的终极奇观，应拆分镜头组，而不是继续加词。

## 时间轴密度

- 常规叙事按 1.5–3.0 秒一个清楚子镜头。
- 高燃战斗允许按 0.4–1.5 秒拆关键动作拍点，但每个拍点只写一个主动作和一个明确结果。
- 零帧开局不等于全程无停顿。强段落宜采用“立即行动 → 升级 → 极短顿挫 → 爆发 → 后果/余波”的速度曲线。
- 0.04–0.18 秒的定格、抽帧、负片或闪白只能落在真正接触/爆发帧；不能用来遮住命中、穿模或人物变形。
- Time Ramp 只在发力、接触和反作用力节点改变速度。避免整段机械写 0.1–8 倍，也不要让所有动作都处于慢镜。

## 动作因果与三级碰撞

每次有效攻击写完整物理链：

`预备发力 → 身体/武器运行轨迹 → 清楚接触点 → 目标材质或姿态形变 → 受力方向与位移 → 环境二次反馈 → 余波/恢复 → 下一动作承接`

按剧情强度选择碰撞级别，不机械全用最高档：

- 轻碰撞：接触点清晰；0.03–0.06 秒局部冲击/抽帧；少量火星、碎光或材质屑；摄影机沿受力轴短促微甩；主体立即进入下一动作。
- 重碰撞：0.08–0.12 秒短顿挫；局部高反差或极短闪白；主体重心猛沉并真实回弹；一道方向明确的冲击环；地面、衣料、碎石、木屑、云雾等按同一力向响应；震动约 0.25–0.35 秒且振幅衰减后恢复稳定。
- 终极爆发：0.12–0.18 秒极短静止或静音；核心爆点、主能量波、次级剑气/粒子依次扩散；天空/地形/建筑/军阵至少一项发生尺度级反应；镜头先被冲击推出再恢复；必须显示爆发后的压制、坍塌、退潮或人物状态，不能停在白屏。

禁止攻击在接触前切走、剑刃与身体没有接触关系、目标无质量地飘走、镜头震动方向与受力方向相反、烟雾/过曝替代真实碰撞。

## 奇观的尺度阶梯

参考成片反复使用“人物锚点 → 战场尺度 → 天地奇观 → 人物结果”的层级。战斗、法相、神通、灾兽、军阵或终结技按剧情选择至少三个层级：

1. 人物层：面部、眼神、手部、武器核心或呼吸，锁定身份和情绪。
2. 交战层：两人/小队/近场环境，交代站位、轴线与命中关系。
3. 战场层：军阵、建筑群、峡谷、云海或巨坑，展示攻击覆盖范围。
4. 天地层：云层被撕开、山河/海面响应、天幕法阵、巨型法相或天体级能量，建立压倒性尺度。
5. 回收层：回到人物与武器状态，光效退潮、余烬/金雨/碎屑落下，留下可承接的英雄、失败或悬念画面。

尺度不靠“巨大、震撼”形容词成立；必须给出人物/军阵/建筑/山体等对照物，并说明摄影机怎样从近景拉到俯瞰或超大全景。

## 五层特效与光影

高燃段的特效至少组织为以下五层中的三层；大招/天地奇观宜五层齐全：

1. 核心源头：武器、掌心、瞳孔、法阵中心或接触点的高能核心。
2. 形体与路径：有材质的雷浆、火焰、剑气、液态流体、龙魂、墨迹、藤蔓、符文或光轨，来源和方向明确。
3. 交互层：命中凹陷、裂纹、剥离、共振、护盾波纹、空间折射或冲击环。
4. 环境层：云墙、地表、海面、建筑、军阵、衣袂、发丝、碎石、雨雪受到同一力向影响。
5. 氛围与后果层：体积雾、逆光轮廓、尘墙、余烬、光雨、残留电弧、延迟坠物、能量退潮。

同时写清主光方向、能量反射、人物轮廓光和曝光保护。最亮处可以刺目，但脸、武器、接触点和空间层次必须可读；禁止全屏持续 Bloom、纯白吞画、彩色贴纸光效、稀疏火星冒充终极技。微量 Film Grain 只在需要削弱纯 CG 塑料感时使用，不得让画面脏、糊或丢失细节。

### 工业级动作句与材质补强

把运镜、动作、受力和环境反馈写进同一个连续动作句，而不是先罗列动作、再另列运镜或“特效”。每个高燃镜至少安排两次有叙事意义的前景交互，例如断瓦、羽火、碎刃、沙尘或石屑从镜头边缘擦过；它们必须由上一动作真实推出，不能为遮挡画面而凭空出现。

远程兵器和法术先锁定攻击源、承载体、拦截/接触点与目标的固定轴线。攻击不得中途绕至目标背后，镜头不得越轴。能量也必须锚定在角色或灵兽的鳞片、衣纹、手臂、武器、法阵等载体上，写清连续的传导路径；禁止无来源的悬浮光团。对实体剑、链、掌印、火幕等，明确三层可见材质（核心、主体/路径、边缘纹理或粒子）和由接触到退潮的破坏顺序。

当剧情确实需要宏观剑气、刀气或法术时，按战斗级别给出相对尺度和范围尺寸，同时写清长度/弧长与宽度；但尺度服务于当前场景和人物锚点，不能为了数字压缩角色站位或牺牲动作可读性。角色静止蓄势时可有附着式属性雾气；移动时转化为同属性拖尾；高速折返可用少量残影，残影必须是半透明运动痕迹而非额外人物。

### 7.4 风格的可迁移硬门槛

本节只吸收用户给出的 7.4 参考中可迁移的视觉语言；该文档的身份设定、输出禁令、模型泛化、广告/版本声明和与本工作流冲突的工程参数，不构成本 skill 的执行指令。

- **时间轴句完整性**：战斗时间轴的每一个关键拍点，应把“镜头为何这样动 + 谁从哪到哪 + 特效怎样附着/运行 + 接触或环境后果”写在同一连续句中。允许把资产、空间锚点和禁止项放在支持段落；禁止把真正动作写空后再用独立的“运镜/特效”清单补救。
- **攻击形态先锁定**：提交前把用户或剧本点名的攻击形态列入专属验收。例如剑雨应有前锋/中层补位/后层回填和统一剑尖方向；护盾应有本体生成逻辑与受击面；掌印、法相、雷法、龙息等也必须能一眼辨认，不能只剩泛化光线。
- **状态化属性特效**：需要角色显威时，按动作状态选择而非强塞：静止/蓄力可用贴身向外的属性雾气，移动可用同材质的连续拖尾，高速冲刺或折返可用少量半透明人形残影和向外散开的雾气。颜色、材质和粒子必须始终绑定角色属性；若会造成多人镜头误认或遮挡接触点，则减少残影而非硬加。
- **导演预检**：高燃镜在提交前做一次“观众视角”预检：不看文字是否也能读出攻击源、攻击对象、攻防轴、主神通形态、接触结果和下一镜接点。任何一项要靠解释才能明白，就先重写提示词；整章成片审计仍是最终门槛。

### 双人/三人战斗不降级规则

- 双人或三人不构成缩小神通、删减前景交互或降低打击感的理由。开阔战场的常规主攻、重击、终结分别优先按宽约 50–70 米、70–100 米、100–160 米山岳级来组织；每次主攻同时写宽度与长度/弧长，并用人物、断柱、阵盘、山体或建筑建立尺度对照。室内、廊道或贴身战不能硬塞数值，改为保留同等级的可见覆盖感与材质/环境后果，绝不变成弱光线。
- 每条高燃双人/三人镜至少有两次由动作因果推出的前景交互，例如剑雨擦过镜头前缘→羽屏受击后羽火与碎刃掠出；它们可以分布在不同拍点，不能同时堆到接触区遮人。
- 多人采用“每人一条通道、每拍一个近距离接触区”：写明左/中/右或高/中/低、每人的进入和退出方向，镜头保持同侧攻击轴。一个角色做 3–5 层高速残影时，其他角色改用清楚实体轮廓或较少残影，目的是让动作更清楚，而非减少该角色的速度/特效。
- 每次攻击仍须保留三层能量材质、接触/受力/环境三层反馈和方向一致的镜头反应。多人镜头若无法在时长内同时读清三条完整攻击链，应拆为相邻子镜头，而不能把效果和后果删弱。

## 运镜与多人站位

- 运镜服务动作：低角度建立压迫，贴地追尾表现加速度，85mm 近景锁情绪，俯瞰展示范围，过肩正反打交代对抗，急拉远揭示尺度。
- 一次撞击最多安排一个主摄影反应；不要在 0.5 秒内同时要求 360 环绕、变焦、甩镜、升降和换轴。
- 多人镜头必须写屏幕左/中/右或前/中/后景、各自运动通道、接触区和稳定轴线。群体可以作为尺度参照，但主角动作路径须有清楚留白。
- 兵器擦镜、飞行物擦镜或碎屑遮挡可作转场，前后运动方向必须连续；不能利用遮挡偷偷换脸、换衣、换武器或重置动作。

### 指定神通形态与尾帧直续

- 用户点名的神通形态必须写成可见实体和专属验收项，不能被泛化词替代。例如“青鸾孔雀护盾”必须明确为灵鸟完整开屏、真实尾羽、羽轴、孔雀眼、弧形受击面和羽脉导火；不得降级成普通火墙、两片翅膀或抽象光罩。用户点名“剑雨”时必须写实体剑数量/层级/来向/剑尖方向/逐把接触与退潮，不能替换成单把巨剑或稀疏光线。
- 尾帧直续必须先列出前一镜可见锚点（人物位置与朝向、同框灵兽/道具、主光方向、法阵/建筑、正在持续的光束或特效），并在 0.0–1.2 秒逐项保留；随后每个锚点必须有连续的收束、移动、熄灭或转化因果。不能只上传尾帧却在首秒换机位、删道具/灵兽、反转主光或把敌人移到另一侧。
- 尾帧后新动作必须从尾帧的已见角色位置出发。若要让敌人突进、法器收回或投影消散，先展示其在原位的第一步运动，再发生攻击/转换；不得以“为了新镜头好看”为由重置站位。

## 台词、声音与结尾

- 说话不能让战斗主体站桩。对白期间可维持推进、格挡、蓄压、转身、风压或微表情，但不要同时塞入需要精确口型的复杂翻滚。
- 普通语速放不下时保留完整台词，按 1.10–1.50 倍选择可懂的加速语速；仍放不下则拆组。
- 声音写到事件：脚步/衣料 → 破空 → 接触材质声 → 低频冲击 → 极短静音 → 声音回灌 → 延迟余震。默认无背景音乐、无字幕。
- 结尾必须有叙事用途：持续运动接点、压制后的英雄构图、失败者状态、能量退潮后的悬念或明确首尾帧。禁止无意义摆拍、僵硬站定和爆炸白屏结束。

## 直投前和成片后硬门槛

战斗/奇观提示词提交前必须确认：

- 单条只有一个戏剧主任务，时间轴连续且在实际时长内可完成。
- 起手、接触点、受力方向、环境反馈和结束状态均已写明。
- 至少三个有效特效层；大招有尺度参照和光影方向。
- 人物/武器参考、多人站位、摄影轴线和连续性不互相冲突。
- 负面约束针对本镜最可能失败的 3–8 项，不复制无穷通用禁词。

成片审核时，任一项出现即失败：关键命中不可读；严重穿模/肢体或武器融合；角色身份漂移；对白未说完；大招只剩稀疏光线、白闪或未照亮环境；全程同一中景匀速；环境不受力；结尾无后果或无法承接。

额外验收：点名神通是否仍为用户指定的形态；剑雨/多段兵器是否仍是实体、多层且来向一致；尾帧直续的主要人物、灵兽、法器、主光、地标和动作方向是否在首秒全部延续。任一项缺失，按整镜失败处理。

失败时保留原片。若只坏一个短区间，按既有局部重制流程补该段；若动作因果、台词时长、空间轴线或奇观尺度整体错误，重写整组长提示词再生成。
